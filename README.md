# Personal Branding - Arya Dhimas

Website personal branding untuk **Arya Dhimas** - Web Developer & Software Engineer.

## 📋 Fitur

- ✨ Loading screen animasi
- 🎨 Dark/Light mode (toggle)
- ⌨️ Efek mengetik (typing effect)
- 🎯 Background partikel interaktif
- 🖱️ Custom cursor
- 📜 Scroll animation
- 🔢 Counter statistik
- 📱 Fully responsive
- 🎪 Portfolio filter
- 📝 Contact form
- ⬆️ Back to top button

## 📁 Struktur Folder

```

├── components/             # Komponen HTML
├── pages/                  # Halaman tambahan
├── docs/                   # Dokumen
├── README.md
└── LICENSE
```

## 🚀 Cara Menjalankan

Buka file `index.html` di browser Anda.

**Atau** dengan Live Server (VSCode):
1. Install ekstensi "Live Server"
2. Klik kanan pada `index.html`
3. Pilih "Open with Live Server"
